# Privacy Policy

Ophthalmology Toolbox does not require an account.

The app does not collect personal information.

Images or photos captured using camera-based tools remain on the user’s device unless the user chooses to save or share them.

The app does not include advertising or third-party tracking.

## App Information

Ophthalmology Toolbox is an educational and clinical reference app that provides practical ophthalmology tools, charts, and quick references.

## Medical Disclaimer
